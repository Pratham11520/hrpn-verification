# HRPN Verification System

> LLM-assisted health-risk verification and medicine-information workflow built around a large Indian medicine dataset.

## Overview

This project explores how LLM applications, structured health information, and retrieval systems can be combined into a practical verification workflow.

## Focus areas

- LLM-assisted health-risk prediction
- Medicine information retrieval
- Large structured medicine datasets
- Python-based AI application development
- Retrieval and prompt-engineering workflows

## Related production work

The project connects to my broader **MediChain / MediDoc** work, where I developed a multi-LLM RAG platform over **254,022 medicine records** with semantic retrieval, deterministic guardrails, and a FastAPI + React application.

## Core technologies

**Python · LLMs · RAG · FAISS · FastAPI · React · Data Processing**
